Notes

Tuning. Each component block starts with its own -- variables for content placement. Adjust those; do not touch the layout rules. If a frame's art differs from what these values assume, the numbers move — the structure does not.

mask-size. Everything here uses 100% 100%, which stretches the art to the box. That is right for the panel, whose height grows with content, but it distorts a frame whose proportions matter. Switch that frame to contain and give the box the asset's own aspect ratio.

Color is two variables. Section 8 is the same markup and the same PNGs four times over; only --frame-ink and --frame-paper change. These frames are D&D 5e's own artwork — other systems supply theirs — but the mechanism is what makes per-system theming cheap.

Nesting needs the child combinator. Frame layers are selected with >, not a descendant space. Without it, a framed component placed inside another framed component inherits the outer mask — which is exactly what broke the saving-throw rows inside the panel.

The badge is one component. Proficiency bonus and speed share a frame, a layout and a type scale. Record that in the coincidences table: two entries on the build list collapse into one.

Roll targets are buttons; reveal targets are buttons too. Both need keyboard access. They differ in treatment, not in semantics — only roll targets change background on hover.
